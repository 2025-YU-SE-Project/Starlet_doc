## 8. Glossary

|           이름            |                                 설명                                  |                    출처 (섹션 및 클래스)                     |
|:-----------------------:|:-------------------------------------------------------------------:|:----------------------------------------------------:|
|     **User (사용자)**      |         플랫폼의 사용자 계정 및 관련 기능 (회원가입, 로그인, 탈퇴 등)을 관리하는 핵심 도메인.         |       [cite_start]3.1, 3.3.1 (User) [cite: 1]        |
|     **Email (이메일)**     |          회원가입/비밀번호 재설정 시 사용되는 이메일 주소 관리 및 인증 메일 발송 관련 기능.           |       [cite_start]3.1, 3.3.2 (Email) [cite: 1]       |
|     **Verify (검증)**     |            이메일 인증 토큰의 생성, 유효성 검증 및 인증 상태를 관리하는 보안/인증 기능.            |      [cite_start]3.1, 3.3.3 (Verify) [cite: 1]       |
|     **Diary (일기)**      |       사용자가 감정 일기를 작성하고, 수정하고, 조회하는 핵심 도메인 및 기능. (별 생성의 기반이 됨)       |       [cite_start]3.1, 3.3.4 (Diary) [cite: 1]       |
|      **Star (별)**       |         일기를 기반으로 생성되며, 위치 조정 및 밤하늘/아카이브 조회 등의 기능을 제공하는 엔티티.         |       [cite_start]3.1, 3.3.5 (Star) [cite: 1]        |
| **Constellation (별자리)** |   사용자가 별들을 묶어 별자리를 만들고, 위치 최신화, 대표 별자리 설정, 아카이브 관리 등을 하는 핵심 도메인.    |   [cite_start]3.1, 3.3.6 (Constellation) [cite: 1]   |
| **Connection (별자리 선)**  |                  별자리 내에서 별들을 연결하는 선(관계)을 나타내는 엔티티.                  |    [cite_start]3.1, 3.3.7 (Connection) [cite: 1]     |
|     **S3 (외부 서비스)**     | Amazon S3를 이용한 파일 저장 및 관리 기능 (예: 프로필 사진, 이미지 업로드)을 담당하는 외부 인프라 서비스. | [cite_start]3.3.8 (External Services : S3) [cite: 1] |
|    **Security (보안)**    | Spring Security를 기반으로 JWT 인증/인가, 접근 제어, 비밀번호 암호화 등을 처리하는 공통 인프라 영역. |        [cite_start]3.2.1 (Security) [cite: 1]        |
|  **Exception (예외처리)**   |            애플리케이션 전반에서 발생하는 예외를 중앙 집중식으로 처리하는 공통 인프라 영역.            |       [cite_start]3.2.2 (Exception) [cite: 1]        |
|   **External Config**   |      AWS S3와 같은 외부 시스템과의 연동에 필요한 클라이언트 및 키 설정을 관리하는 공통 인프라 영역.      |    [cite_start]3.2.3 (External Config) [cite: 1]     |
